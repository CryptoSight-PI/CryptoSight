# CryptoSight

O sistema da CryptoSight faz o monitoramento dos componentes de hardware de máquinas responsáveis pela mineração de criptomoedas. 
Com a possibilidade de personalização dos componentes a serem monitorados, o CryptoSight busca disponibilizar um sistema que faça 
esse monitoramento conforme a necessidade de cada usuário. Tecnologias utilizadas:

- HTML/CSS/JavaScript
- Python
- Java
- AWS
- MySQL
